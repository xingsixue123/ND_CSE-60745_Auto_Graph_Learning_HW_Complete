Ex. 2.5 (20 pts) — Pseudo-code for fork, exec, waitpid, exit
Following the hint, each algorithm below is the kernel-side implementation of the call: the code
the operating system runs when a user process traps into it. All four operate on the process table,
whose entries are process control blocks (PCBs); Current denotes the PCB of the calling process,
and a negative return value is the usual errno convention.
