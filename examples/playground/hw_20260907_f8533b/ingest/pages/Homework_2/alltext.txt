Problem 1: (21 points) 
 
 
 
 
 
 
 
 
 
 
 
One possible organization of the memory hierarchy on an Intel Xeon chip is: 
• 
A 64KB L1 instruction cache. 
o The L1 instruction cache contains only instruction encodings. 
• 
A 64KB L1 data cache. 
o The L1 data cache contains only data words. 
• 
A 512KB unified L2 cache. 
o The L2 cache can contain both data and instruction encodings. 
• 
An 8 MB unified L3 cache. 
o The L3 cache can contain both data and instruction encodings. 
 
Suppose this chip has the clock frequency at 2.0 GHz, and for its cache system, assume that: 
• 
All caches use the block size of 128 Bytes. 
• 
The hit time for either L1 cache is 1 clock cycle (CC); the hit time for L2 cache is 10 CCs. 
• 
The time required to find data (i.e., hit time) in the L3 cache is 50 CCs. 
• 
If data is not found in the L3 cache, the processor must look for data in main memory. 
o The processor-to-memory bus can accommodate 16 Bytes of memory at a time. 
o The L3 miss penalty is the initial time required to access memory, which accounts for a 
single transfer (equal to the bus bandwidth, in this case 16 Bytes), plus 10 CCs for every 
additional transfer (also 16 Bytes here). 
 
Hint: for a cache miss, cache miss penalty (transfer time) is an additional cost on top of the hit time 
(access time). A cache miss happens after first attempting to access it.
