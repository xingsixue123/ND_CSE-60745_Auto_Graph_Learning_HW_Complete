\section{Task 4 --- Heterogeneous Graph Embedding (optional practice)}
\label{p2:sec:main}

\subsection{Method}
\label{p2:sec:method}

\paragraph{The graph.}
$H_{\mathrm{train}}$ is the notebook's \texttt{add\_artists(G\_train)}, used verbatim:
$15{,}466$ nodes ($7{,}624$ users $+$ $7{,}842$ artists) and
$19{,}464 + 3{,}014{,}361 = 3{,}033{,}825$ edges.  Every figure in the provided
statistics file is reproduced exactly: $7{,}451$ users like at least one artist and
$173$ like none, while artists per user has median $400$ and max $944$, matching the
table printed in the task description.  The artist layer is $155\times$ denser
than the social layer, and that single fact drives every result below.

\paragraph{What is reused unchanged.}
This is what makes the comparison in Table~\ref{p2:tab:main} legitimate, so I state it
precisely.  \texttt{train\_embedding}, \texttt{LinkPredictor} and
\texttt{CountryClassifier} are \emph{the same Python objects} measured in Task~3: my
sampler is a subclass of Task~3's \texttt{WalkEmbedding} that overrides
\texttt{sample\_walks} and nothing else, and Task~3's module is imported byte-identically
(verified by \texttt{sha256}).  The walk budget ($10$ walks $\times$ length $40$ per
node) and every Skip-Gram hyper-parameter ($d{=}128$, window $5$, $5$ negatives,
$5$ epochs, \texttt{workers=1} for bit-exact reproducibility) are unchanged.  Evaluation
is \texttt{run\_experiment} with $H_{\mathrm{train}}$ and $N_{\mathrm{users}}+N_{\mathrm{artists}}$,
slicing $Z$ to $[:N_{\mathrm{users}}]$; degree buckets are always taken from the
\emph{social} graph $G_{\mathrm{train}}$.  \textbf{The sampler and the graph are the only
things that change.}

\paragraph{Schema convention.}
A schema is a symmetric type string whose repeating cycle is \texttt{schema[:-1]}:
\textsf{U-A-U} gives $\mathsf{U\,A\,U\,A}\dots$, \textsf{U-U-A-U} gives
$\mathsf{U\,U\,A\,U\,U\,A}\dots$, \textsf{U-U-U-A-U} gives $\mathsf{U\,U\,U\,A}\dots$
At each step the next node is drawn uniformly from the neighbours of the type the schema
demands.  Since \textsf{U-A-U-U} is a cyclic rotation of \textsf{U-U-A-U} and yields the
same multiset of step types, I run one schema per rotation class.  The three schemas then
form a one-parameter family indexed by the fraction of steps forced to be social ---
$0$, $1/3$, $1/2$, with Task~3's DeepWalk as the $1$ endpoint --- which is the axis of
Figure~\ref{p2:fig:social}.

\paragraph{Artist start nodes.}
\texttt{embed\_graph} starts walks from \emph{every} node of $H$, artists included.
I rotate the cycle to the start node's type rather than discarding artist starts, so an
artist begins $\mathsf{A\,U\,A\,U}\dots$ --- the same meta-path read from the other end;
artists thus get trained vectors that serve as shared context for users, and are sliced
off before evaluation.  A walk that cannot take its first step (a user with no artist
under \textsf{U-A-U}; a socially isolated user under \textsf{U-U-A-U}) is dropped, exactly
as Task~3's sampler returns \texttt{[]} for an isolated node, so such users keep an
all-zero row in both tasks and the cold-start comparison stays like-for-like.  Under
\textsf{U-A-U} this gives $(15{,}466-173)\times 10 = 152{,}930$ walks.

\paragraph{One idea of my own: rare-artist sampling.}
A uniform $\mathsf{U}\to\mathsf{A}$ step lands on a popular artist far more often than a
niche one, and a shared taste for a top-$100$ artist says almost nothing about two users.
I therefore add an optional weighting in which a step \emph{into} an artist is drawn with
probability $\propto \deg(a)^{-\alpha}$ (steps into a user stay uniform).  At $\alpha{=}1$
this lowers the median popularity of the artist a walk actually visits from $613$ to
$205$ --- i.e.\ to the median popularity of an artist in the dataset, removing the
sampling bias towards hubs.

\begin{lstlisting}[style=p2code,caption={The meta-path sampler. Everything else --- training, link
predictor, country classifier --- is unchanged from Task 3.},captionpos=b,label=p2:lst:sampler]
class MetaPathWalkEmbedding(WalkEmbedding):      # Task 3's class, one method overridden

    def __init__(self, schema="UAU", alpha=None, seed=RANDOM_SEED, **params):
        super().__init__(seed=seed, **params)
        assert schema[0] == schema[-1]           # schema must be symmetric
        self.schema, self.cycle, self.alpha = schema, schema[:-1], alpha

    def sample_walks(self, G, start):
        tables, ntype = self._typed_tables(G)    # node -> {type: (nbrs, cum_weights)}
        t0 = ntype[start]
        if t0 not in self.cycle:
            return []
        k = self.cycle.index(t0)
        rot = self.cycle[k:] + self.cycle[:k]    # rotate the cycle to the start's type
        m, L, rng = len(rot), self.walk_length, self._rng

        walks = []
        for _ in range(self.num_walks):
            walk, i = [start], 0
            while len(walk) < L:
                entry = tables[walk[-1]].get(rot[(i + 1) % m])
                if entry is None:                # no neighbour of the required type
                    break
                nbrs, cum = entry
                walk.append(rng.choice(nbrs) if cum is None      # uniform
                            else rng.choices(nbrs, cum_weights=cum, k=1)[0])  # rare-artist
                i += 1
            if len(walk) > 1:
                walks.append(walk)
        return walks
\end{lstlisting}

\noindent
\texttt{\_typed\_tables} is built once per graph from the notebook's
\texttt{typed\_adjacency(G)} and cached: for each node it stores the neighbour
\emph{list} per type, plus cumulative $\deg(a)^{-\alpha}$ weights when rare-artist
sampling is on.  Sampling a step is therefore $O(1)$ (or $O(\log d)$ weighted), and the
whole $\sim\!152{,}930$-walk corpus takes $2$--$8\,$s against $\sim\!115\,$s of Skip-Gram
training.

\subsection{Protocol, and one control that matters}
\label{p2:sec:protocol}

Every configuration is run at seeds $\{0,1,2\}$ and all reported numbers are $3$-seed
means; the ``noise floor'' row of Table~\ref{p2:tab:main} is the mean within-configuration
standard deviation, which is what licenses calling a gap real.

One confound must be removed before any Task~4 number can be compared with a Task~3
number.  Task~3 walks from the $6{,}958$ non-isolated \emph{users} ($69{,}580$ walks);
every Task~4 run walks from all $15{,}466$ nodes of $H$ ($\approx\!152{,}930$ walks), a
$2.2\times$ larger Skip-Gram corpus, so a naive reading would credit the artist structure
with a gain that is really just more training data.  I therefore ran \textbf{DeepWalk on
the social graph with $22$ walks per node} ($6{,}958\times22 = 153{,}076$ walks, matching
the Task~4 corpus to within $0.1\%$).  That is the row Task~4 must actually beat, and it
changes the conclusion: the extra budget alone is worth $+0.0170$ test Hit@1 and
$+0.0085$ test MRR, but nothing on country classification ($-0.0004$ micro-F1).

\subsection{Analysis}
\label{p2:sec:analysis}

\paragraph{Aggregate link prediction: no, the artists do not help.}
\textsf{U-U-U-A-U} reaches test Hit@1 $0.6163$ against the budget-matched control's
$0.6179$ --- a gap of $-0.0016$, or $-0.3$ noise sd, i.e.\ nothing.  On test MRR it is
$0.7361$ versus $0.7292$, $+0.0070$ or $+2.1$ sd, a marginal edge at best.  Compared
against the \emph{unmatched} $10$-walk DeepWalk the same schema looks like a clean
$+0.0154$ Hit@1 win, and that apparent win is almost entirely the larger walk corpus.
This is the main reason the control was worth running: without it the honest answer here
inverts into a false positive.

\paragraph{Cold-start users: yes, dramatically, and this is not a budget artefact.}
$666$ users have no friend in $G_{\mathrm{train}}$ and receive an all-zero row from any
purely social walk; $216$ test queries have such a source.  Their test Hit@1 is $0.0447$
for Task~3 DeepWalk and $0.0494$ for the budget-matched control --- the extra corpus buys
them nothing, because no amount of walking reaches a node with no edges.  But $647$ of
those $666$ users ($97.1\%$) like at least one artist, with a median of $334$ artists
each, and $209$ of the $216$ cold test sources ($96.8\%$) are covered.  Through the
artist layer they become reachable, and their Hit@1 rises to $0.2824$ under
\textsf{U-U-U-A-U} and $0.3596$ under \textsf{U-A-U} --- respectively $5.7\times$ and
$7.3\times$ the control, gaps of $8.3$ and $11.0$ times the $0.0282$ mean seed spread of
this bucket.  This is the one place where the heterogeneous structure does something no
amount of social-graph effort can.

\paragraph{Signal or noise? Both, and density decides which.}
A \textsf{U-A-U} step connects two users who share \emph{any} artist.  Sampling $40$
users, the median number of others reachable in one such step is $7{,}307$ of $7{,}623$
--- \textbf{about $96\%$ of the graph} --- against a median social $2$-hop neighbourhood
of $61$.  A U-A-U edge is therefore almost devoid of information: it is not far from a
link to a uniformly random user.  That explains the whole shape of
Table~\ref{p2:tab:degree}.  For a user with $\ge16$ friends the social graph already
supplies a sharp, small candidate set, and diluting it with a near-complete graph costs
$0.6644 \to 0.3785$ Hit@1.  For a user with $0$ friends the alternative is not a sharper
signal but an all-zero vector and chance-level ranking, so even a weak ordering --- the
artist layer is near-complete but not uniform, and how \emph{many} artists two users
share still varies --- is worth a great deal.  Same edges, opposite value, depending
entirely on what the user already had.

\paragraph{The meta-path constraint is doing real work.}
A type-blind DeepWalk on $H$ takes a social step only $0.72\%$ of the time (measured over
$31{,}122$ sampled steps), because a user has $\sim\!395$ artist neighbours and $\sim\!5$
social ones; it is \emph{de facto} \textsf{U-A-U}.  Yet it beats explicit \textsf{U-A-U}
on every column ($+0.0401$ test Hit@1).  Those rare social steps are worth a great deal,
which is precisely the metapath2vec argument: on a graph this lopsided, leaving the
transition rule to the degree distribution throws away the sparse, informative edge type,
and the schema is how you take that choice back.  The stronger form of the same point is
the monotone family in Figure~\ref{p2:fig:social}: as the forced social fraction rises
$0 \to 1/3 \to 1/2$, overall test Hit@1 goes $0.4133 \to 0.5525 \to 0.6163$ while the cold
bucket goes $0.3596 \to 0.2994 \to 0.2824$.  Notably the cold bucket does \emph{not}
collapse to the $0.0494$ of a pure social walk even at $1/2$, because although a socially
isolated user can never start a \textsf{U-U-U-A-U} walk, the $\mathsf{A}\to\mathsf{U}$
step lets other walks reach them.

\paragraph{Country classification: helped on micro-F1, hurt on macro-F1.}
Against the budget-matched control, \textsf{U-U-U-A-U} gains $+0.0263$ test micro-F1
($0.7887$ vs $0.7624$, $7.0$ sd) and loses $-0.0498$ test macro-F1 ($0.6353$ vs $0.6852$,
$9.1$ sd).  Both are far outside the noise, and the split between them is interpretable:
music taste is regional, so artists carry genuine country signal and lift the large
classes that micro-F1 measures --- but that signal is coarse, regional rather than
national, while macro-F1 is dominated by the small countries, which in the social graph
are tight, well-separated communities that the near-complete artist layer blurs together.
Task~3's triadic walk remains the best model in the study for macro-F1 ($0.6974$) and no
heterogeneous variant comes close.

\paragraph{Rare-artist sampling works, and confirms the diagnosis.}
Weighting $\mathsf{U}\to\mathsf{A}$ by $\deg(a)^{-1}$ improves plain \textsf{U-A-U} on all
eight columns: $+0.0129$ test Hit@1 ($2.6$ sd), $+0.0094$ test MRR ($2.9$ sd), $+0.0368$
test micro-F1 ($9.7$ sd) and $+0.0491$ test macro-F1 ($9.0$ sd).  Since the only change is
which artist a walk passes through, this is direct evidence that it is specifically the
\emph{popular} artists that inject the noise, and that the density problem is partly
fixable inside the sampler.  It does not rescue \textsf{U-A-U} to competitiveness --- the
schema is still missing the social edges that matter most --- but it is the largest
single improvement I obtained over a baseline schema.

\subsection{Conclusion}
\label{p2:sec:conclusion}

Heterogeneous structure helped \emph{one} of the two downstream tasks and one
sub-population, and hurt elsewhere.  It did essentially nothing for aggregate friend
recommendation once the walk budget was matched; it improved country micro-F1 by a wide
margin and degraded macro-F1 by a wider one; and it improved cold-start friend
recommendation by roughly $7\times$, which is the result worth keeping.  The practical
recommendation that follows is not a single best schema but a split one: use a
social-graph walk (Task~3's triadic) for users who have friends, and a
\textsf{U-A-U} walk --- ideally with rare-artist weighting --- for the $9\%$ of users who
do not.  Table~\ref{p2:tab:degree} says the crossover sits between degree $0$ and
degree~$1$.  The broader lesson is that on a graph where one edge type is $155\times$
denser than the other, the meta-path is not a modelling flourish but the only thing
standing between the walk and a near-complete graph.
