Q3: Graph Creation (10 pts)
The edge list graph.txt (attached to this assignment as graph-1.txt) contains 26,377 tab-
separated lines, each giving one undirected edge. It was loaded into a simple undirected graph
(networkx.Graph), adding one node per distinct identifier appearing in the file and one edge
per line; no isolated nodes were added and the file was not symmetrised a second time. The
file contains no self-loops and no duplicate edge in either orientation, so the 26,377 lines yield
exactly 26,377 distinct edges.

Answer. The graph has 26,728 nodes, 26,377 edges and 4,104 connected components.
The graph is therefore very sparse (mean degree 2m/n ≈1.97) and highly fragmented. It is not
a forest: a forest on n nodes with c components would have n −c = 26,728 −4,104 = 22,624
edges, whereas the graph has 26,377, so it carries m −n + c = 3,753 independent cycles.
