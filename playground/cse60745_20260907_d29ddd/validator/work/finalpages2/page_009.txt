Admissibility of the default α.
Katz centrality is well defined only for α < 1/λmax. For this
graph λmax = 8.762217, so 1/λmax = 0.114126. The default α = 0.1 satisfies 0.1 < 0.114126,

converged and every entry of the unnormalised solution is positive.
