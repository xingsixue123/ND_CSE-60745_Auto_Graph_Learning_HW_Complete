to address over-smoothing problem in deep GNNs. Please refer to PyG documentation for more 
technical details and use Google Colab for experiments. For each question, you will be asked to 
complete a MessagePassing() subclass as shown in the example below, where you need to 
specify the required components and aggregation strategy in __init__(), define propagated 
message in message(), and implement aggregation and node updation in forward(). You also 
need to complete reset_parameters() for parameter initialization.

Q5: Mitigate Over-Smoothing in Deep GNNs (6 pts)
Stacking too many GNN layers will make all node embeddings drift towards each other and cause 
over-smoothing problem. Please look into the literature on over-smoothing and implement 
MyDeepConv() to design a GNN model that stays useful with an 8-hop receptive field. Note that 8-
hop receptive field is not equal to 8-layer GNN.
