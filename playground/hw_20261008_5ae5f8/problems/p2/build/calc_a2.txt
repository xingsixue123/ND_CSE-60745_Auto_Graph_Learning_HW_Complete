
Supporting magnitudes for Ex. 3.2.

Question: if we built one giant memory out of "the fastest materials available",
as big as some terabytes, would that remove the need for a memory hierarchy?

The answer rests on the claim that CAPACITY ITSELF COSTS LATENCY, independent of
what the cells are made of, because a signal has to physically cross the array.
This script puts numbers on that claim so the answer does not assert any figure
that was not computed.

Everything below is arithmetic on three published/physical constants; nothing is
simulated and nothing is fitted.

========================================================================
1) Physical size of a 1 TB array of the DENSEST real memory cells
   (bit cell = 0.021 um^2, 1 TB = 1e+12 bytes = 8.0e+12 bits)

  bit cells only (array efficiency 100%, impossible):
    cell area ........... 168,000 mm^2  (2.38 x a 300 mm wafer)
    square side ......... 410 mm  (0.41 m)
    light, one way ...... 1.37 ns
    light, round trip ... 2.73 ns  = 11 cycles at 4 GHz

  with periphery (array efficiency 70%, generous):
    cell area ........... 240,000 mm^2  (3.40 x a 300 mm wafer)
    square side ......... 490 mm  (0.49 m)
    light, one way ...... 1.63 ns
    light, round trip ... 3.27 ns  = 13 cycles at 4 GHz

========================================================================
2) Latency floor vs. capacity: same cell, same material, only size changes.
   A square array's side goes as sqrt(capacity), so the speed-of-light
   round trip does too. This is the whole argument in one table.

       capacity   side (mm)   c round trip    cycles @ 4GHz
    32 KB  (L1)        0.09       0.001 ns              0.0
    1 MB   (L2)        0.50       0.003 ns              0.0
    32 MB  (L3)        2.84       0.019 ns              0.1
           1 GB       16.05       0.107 ns              0.4
           1 TB      489.90       3.268 ns             13.1

   ratio 1 TB : 32 KB  side = 5,524x   (= sqrt(30,517,578) = 5,524)

========================================================================
3) The number the answer actually quotes.
   A 1 TB array of the densest available cells is at least ~0.4 m across.
   Crossing it and returning takes >= 2.7 ns IN VACUUM, i.e. >= 11 clock
   cycles at 4 GHz, before a single transistor switches.
   Real on-chip signalling is several times slower than c (RC-loaded wires,
   repeater stages), so this is a floor, not an estimate.

   For comparison, a real L3 cache answers in ~40 cycles. So the giant
   device's *physical lower bound* is already in L3 territory (11 cycles),
   and nothing about the choice of material can move it.
